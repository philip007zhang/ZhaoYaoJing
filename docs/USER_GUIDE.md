# 本地使用手册

首次使用：双击安装脚本，再双击启动脚本。已有导出分析只需Gemini密钥；采集还需已登录、版本兼容的微信及合法配置的wxautox4。页面只显示密钥是否配置，绝不显示值。

起始和截止日期可选过去30天内任意两天，均包含当天。默认保留最近结束的一周。准确输入群名。先选采集流程，再选择是否解读媒体、是否强制重新采集。采集时保持微信登录并避免同时操作窗口。

“采集并分析”先查已有周记录；“分析已有记录”使用选中的目录，必要时明确允许部分数据；“复用分析分片”同时选择采集及分片目录，只调用最终汇总，新提示词不重做旧分片。

刷新浏览器不会停止服务端任务。一次只允许一个任务，避免争用微信窗口。停止会终止子进程，已完成文件保留，最新回调日志可能不完整。

历史读取超时可能已移动微信位置。即使后来读到起始日期，只要超时区间尚未恢复，结果仍标为部分采集，不自动复用为完整周记录。回调日志保留以供恢复；可重新采集，或明确选择“允许分析部分记录”。

右侧可查看历史报告、切换精简文本和截图排版。复制按钮复制全文。独立打开排版后可浏览器整页截图或打印PDF。磁盘中的wechat-01.txt等是分条发送版本，不自动发送。

导入找不到文件：--input只读取已有JSON，直接采集不需要它。模型HTTP错误：检查密钥、模型权限和配额。引用警告：不会中断，可查citation_warnings.json。端口占用可运行 `python local_app.py --port 8766`。不要将本服务暴露公网。

默认周报采用简短章节和列表，不展示Message ID。旧长报告不会自动覆盖，选择原分片重新汇总即可生成新格式。

采集过程遇到微信群视频会保留消息但跳过可能无限等待的菜单下载。媒体开关仍支持公开链接和已取得的视频。5分钟无新日志时页面提示检查；停止会结束Windows进程树。

选择已有采集记录时会带出原起止日期，可缩小范围重新分析，原数据不覆盖。复用原分片则不能改变日期；超出已有范围需要采集。
