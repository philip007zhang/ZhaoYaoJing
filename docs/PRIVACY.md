# 隐私与发布

群聊记录、媒体、昵称、报告、提示词均可能包含私人信息。outputs和.local默认被Git忽略；这不等于加密，应按本机权限及备份策略管理。

用户启动分析后才向Google提交选定内容。媒体开关还会获取公开地址并提交正文或视频。程序不读取浏览器Cookie、不绕过登录、不自动群发。服务方保留与费用规则取决于账户及当前条款。

服务仅绑定127.0.0.1；写请求需要启动时生成的令牌，校验Host并限制结果文件路径；预览iframe无脚本权限。没有公网、多用户登录或远程部署设计。

网页临时密钥只存在服务及其子进程环境，不持久化。用户自行设置的Windows环境变量不自动删除。泄露密钥应撤销换新，不上传、不截图或粘贴到聊天中。

仓库只发布自有应用代码、测试、静态UI及文档；不包含真实聊天、报告、虚拟环境、日志、激活器、exe或第三方商业库授权。
